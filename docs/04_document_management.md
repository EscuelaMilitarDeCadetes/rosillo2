# Gestión de documentos

Los documentos se almacenan en el servidor de archivos.

No se guardan en la base de datos.

La base de datos solo guarda la ruta.

## Rutas de almacenamiento

CONVOCATORIA
PRESUPUESTO
PROYECTO
TRABAJO_GRADO
PLANTILLA

## Tablas utilizadas

DocumentoFirma
DocumentoFirmante
TipoDocumento
